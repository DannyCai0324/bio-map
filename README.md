# 翊の生物

高中生物自學網站：課堂講義 + 題庫刷題 + 課外補充。

**網站**：https://dannycai0324.github.io/bio-map/

## 內容

| 區塊 | 內容 |
|---|---|
| 學習 | 50 篇課堂講義，依九大主題分層瀏覽；每篇含心智圖、類比、易錯提醒、補充資料、重點回顧 |
| 開始練習 | 626 題，段考／學測／分科三種模式，可自選範圍與題數 |
| 課外補充 | 10 篇大學程度延伸文章（醫學與生技、分子與細胞、人體運作、演化與多樣性）|
| 熟練度 | 各要點答對率統計，並可下載／還原進度備份（換裝置時用）|
| 錯題本 | 自動收錄答錯的題目 |

依 108 課綱九大主題、50 個要點編排，涵蓋必修生物與選修生物 I–IV。

## 題目來源與授權

- **歷屆公開試題**：大考中心指定科目考試、分科測驗生物科試題。依著作權法第 9 條第 1 項第 5 款，考試試題不得為著作權標的。
- **自編原創題**：本專案自行命題，每題附詳解與易錯提醒。

本專案**未收錄任何出版社評量卷、講義或教科書內容**。

## 給學生的使用說明

- 作答紀錄存在自己裝置的瀏覽器裡，關掉再開還在，網站更新也不會清掉。
- 換手機或平板時，到「熟練度」頁面按〈下載備份〉存成檔案，在新裝置按〈還原備份〉讀回來。
- 手機可加入主畫面當 App 使用，離線也能讀講義、練題目。
- 手機返回鍵會退回上一個畫面，不會直接關掉。

## 技術

單一 HTML 檔，無需後端。資料以 JSON 內嵌，學習進度存於瀏覽器 localStorage。
Service worker 採「網路優先、斷網回退快取」策略，確保內容更新後使用者不會卡在舊版本。

## 更新方式

替換 `index.html` 後 commit、push，GitHub Pages 約一分鐘內自動更新。
